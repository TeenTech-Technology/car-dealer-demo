# DriveZed Motors — car dealership demo

A showcase demo website for a **fictional** Lusaka car dealership (buy, rent, finance). Built by **Teen Tech Technology** as a sales demo.

Live: https://teentech-technology.github.io/car-dealer-demo/

- Plain HTML/CSS/JS single-page app (hash routing), no backend, no build step.
- All data (cars, bookings, enquiries, favourites) is stored in the browser's localStorage.
- Mobile-money deposit is a **TEST MODE simulation** — no real payments.
- Admin: `#/admin` (demo password is shown on the login page).
- All vehicles are sample stock; photos are illustrative, from Unsplash (Unsplash License).
- Phone/WhatsApp numbers are placeholders.
